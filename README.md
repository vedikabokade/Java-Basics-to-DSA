# Java-Basics-to-DSA

A collection of Java programs and coding problems created while learning and practicing **Java programming, Object-Oriented Programming, Data Structures, Algorithms, and problem-solving**.

This repository contains beginner-friendly Java programs as well as implementations of common DSA and algorithmic problems. The purpose of this repository is to practice concepts by writing and experimenting with code.

---

## 📚 Topics Covered

### 1. Java Basics

Programs covering the fundamentals of Java:

* Hello World
* User Input
* Variables and Data Types
* Operators
* Conditional Statements
* Loops
* Functions / Methods
* Classes and Objects
* Basic OOP concepts
* Calculator programs

### 2. Pattern Printing

Practice problems for improving logical thinking and understanding nested loops.

Examples include:

* Star patterns
* Number patterns
* Pyramid patterns
* Diamond patterns
* Symmetric patterns

### 3. Arrays

Basic array operations and problem-solving using arrays.

Topics include:

* Array traversal
* Searching
* Finding maximum/minimum elements
* Array manipulation
* Frequency-based problems
* Array-based coding problems

### 4. Strings

Programs for understanding Java Strings and string manipulation.

Topics include:

* String input
* String concatenation
* String length
* `charAt()`
* `compareTo()`
* `substring()`
* String reversal
* Palindrome checking
* `StringBuilder`
* Character frequency
* Finding frequently occurring characters

### 5. Recursion

Programs designed to understand recursive thinking and function calls.

Problems include:

* Printing numbers using recursion
* Sum of first `n` natural numbers
* Factorial
* Fibonacci series
* Power calculation
* Optimized power calculation
* Tower of Hanoi
* Reversing a string using recursion
* Other recursive problem-solving exercises

### 6. Sorting Algorithms

Implementation and practice of common sorting techniques:

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

The repository also provides examples for understanding how sorting algorithms work through code.

### 7. Data Structures

Practice implementations and problems related to fundamental data structures.

Topics include:

* Linked Lists
* Nodes
* Stacks
* Basic data structure operations
* Data structure problem-solving

### 8. Bit Manipulation

Programs for practicing operations at the bit level.

Topics include:

* Bitwise operators
* AND, OR and XOR
* Bit shifting
* Checking and manipulating individual bits
* Common bit manipulation problems

### 9. Backtracking

Problems that demonstrate how backtracking can be used to explore possible solutions.

Examples include:

* Recursive search
* Constraint-based problem solving
* Graph-related backtracking problems
* Exploring possible paths

### 10. Algorithms and DAA

The repository also contains implementations related to **Design and Analysis of Algorithms (DAA)**.

Examples include:

* Closest Pair of Points
* Hamiltonian Cycle
* Travelling Salesman Problem (TSP)
* Stack-based problems
* Graph algorithms
* Backtracking-based solutions

### 11. Competitive Programming Practice

Additional coding problems and implementations are included for improving:

* Problem-solving
* Logical thinking
* Algorithmic thinking
* Time and space complexity awareness
* Coding speed

## ▶️ How to Run

### 1. Install Java

Make sure Java is installed on your system.

Check your Java version:

```bash
java -version
```

Check the Java compiler:

```bash
javac -version
```

### 2. Clone the Repository

```bash
git clone https://github.com/your-username/Java-Practice.git
```

### 3. Open the Project

```bash
cd Java-Practice
```

### 4. Compile a Java Program

For example:

```bash
javac helloworld.java
```

### 5. Run the Program

```bash
java helloworld
```

For programs that require user input, enter the required values in the terminal when prompted.
